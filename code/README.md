Код учебный. Перед использованием сверьте имена узлов, ассоциаций и полей с транзакцией BOBF вашей системы.
Места, которые нужно проверить, отмечены комментарием `CHECK`.

Минимальная версия ABAP — 7.40 SP08: используются inline-объявления и конструкторы `VALUE` и `NEW`.
